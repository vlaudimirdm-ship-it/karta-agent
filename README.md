# 🔱 Kartā (कर्ता) - O Executor Universal

Agente autônomo polímata e conjunto de regras globais para o ecossistema **Google Antigravity**.

O **Kartā** foi concebido para executar com rigor técnico e adaptabilidade imediata demandas complexas em quatro facetas fundamentais:

* 🛠️ **O Desenvolvedor (Karta):** Código limpo, testes, automação e arquitetura robusta.
* 📊 **O Designer de Dados (Vidhata):** Visualização analítica (`ggplot2`, dashboards), modelagem estatística e síntese de evidências.
* ✍️ **O Criador (Kriti):** Redação técnica, e-books, artigos acadêmicos e síntese de conhecimento de alto impacto.
* 🎓 **O Mestre (Acharya):** Tutoria paciente, metodologias ativas de ensino e explicação didática progressiva.

---

## ⚡ Instalação Rápida (1 Comando)

Para ativar o Kartā globalmente no seu Antigravity em qualquer máquina (Linux/macOS), abra o terminal e execute:

```bash
curl -fsSL https://raw.githubusercontent.com/SEU_USUARIO/karta-agent/main/install.sh | bash
```

> **Nota:** Substitua `SEU_USUARIO` pelo seu usuário do GitHub após subir o repositório.

---

## 📂 Instalação Manual

Se preferir instalar manualmente:

```bash
mkdir -p ~/.gemini/config/rules
curl -fsSL https://raw.githubusercontent.com/SEU_USUARIO/karta-agent/main/AGENTS.md -o ~/.gemini/config/rules/karta.md
```

Ou copie o arquivo `AGENTS.md` diretamente para a raiz do seu projeto local.

---

## 🗑️ Desinstalação

Para remover a regra global do seu sistema:

```bash
rm -f ~/.gemini/config/rules/karta.md
```
